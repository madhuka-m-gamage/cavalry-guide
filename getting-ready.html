Quick start

Any clear phrasing that names the phase works. These are the prompts used in this guide.

1. Audit

/cavalry:recon Audit the whole repo, parallel mode.

Pre-flight reports in one block; Recon audits read-only, asks decisions in batches of four, and builds the queue with Deploy values.

2. Protect

/cavalry:fortify

Characterization tests for risky paths, a shared backend mock, and required CI.

3. Fix

/cavalry:charge Use Mode C: merge to staging yourself, pause after Q5.

One branch and PR per item, merged to staging on green checks; one line per merge; a Rally Point at Q5.

Any time

/cavalry:status

4. Restructure (optional)

/cavalry:regroup

5. Roll out

/cavalry:breach
