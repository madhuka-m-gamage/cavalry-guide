Script limits

cavalry-decl-diff

  • JS/TS only; anything else exits 2.
  • Top-level only: removed class methods and export { a, b } entries are not detected.
  • In const a = 1, b = 2 only the first name is tracked.

Not detected: a class method and an export-list entry removed

$ cavalry-decl-diff src/BulkEmailModal.tsx
5 declarations, none removed
[exit 0]
$ cavalry-decl-diff src/app.css
cavalry-decl-diff: unsupported extension .css; supported: .js .jsx .ts .tsx .mjs .cjs .mts .cts
[exit 2]

cavalry-move-codemod

  • Rewrites code imports, including tracked CSS imports and the moved file's own relative imports.
  • Leaves docs, config files and CSS @import/url() untouched.
  • Only wildcard paths aliases; refuses existing destinations and untracked sources.
$ cavalry-move-codemod moves-3.txt --apply
cavalry-move-codemod: destination src/lib/firebase.ts already exists
[exit 2]
$ cavalry-move-codemod moves-4.txt
cavalry-move-codemod: src/ghost.ts is not a tracked file or directory
[exit 2]

cavalry-verify-pure-move

  • A heuristic: an import line that also gains logic still passes. The test gate and your review still matter.

Passes: a dynamic import that gained .then(…)

$ cavalry-verify-pure-move
pure move against HEAD: 2 renamed, 2 modified (import lines only)
[exit 0]
